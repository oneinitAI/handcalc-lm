# AI 学习本（AI Notebook）产品需求文档

> **副标题**：给你权重，亲手算出它的下一句话
>
> **一句话定位**：一个在浏览器内、用纯 JS 从零构建微型 Transformer 的互动教学项目——用户作为"大模型训练师"，亲手完成 预训练 → 微调(SFT) → 偏好对齐(DPO) 三阶段真实训练，并随时用显微镜/注意力直播看清模型的每一个数字。

- **版本**：v0.1（草案）
- **日期**：2026-08-21
- **状态**：讨论中（推理区已定稿，训练性能待实测）

---

## 1. 项目概览

### 1.1 定位
- **教学项目**，非工具项目。核心目标不是"做出一个好模型"，而是"让用户看懂 LLM 是什么"。
- 全浏览器运行，**无后端**。模型在用户浏览器里真实训练、真实推理，结果不可预设。
- 用网页呈现"构建 → 使用"的完整过程，用户是参与者而非观众。

### 1.2 核心精神
> **没有魔法，只有乘法。**

LLM 不是黑箱魔法，而是一堆具体数字（权重）和一个确定性计算流程（前向传播）。项目的最高使命是**祛魅**：把"敬畏魔法"变成"看穿玩具"。

### 1.3 目标受众：雅俗共赏
- **新手层**：完全没接触过 ML——用直觉化的比喻讲清概念。
- **进阶层**：懂点编程/ML——看到完整的公式、权重数字、算法细节。
- 通过"双层讲解"（见 §8）同时满足两层，不偏废。

### 1.5 UI 定位：UI 即艺术品（核心支柱）
- 本项目**不是"教学内容的容器"**，而是**数字艺术品**：Web UI 意味着无限可能，界面必须惊艳。
- 艺术级 UI 的定义：**审美与内容的高度统一**——每个视觉决策都服务于项目灵魂（祛魅/手算/看得穿），而非装饰性特效。
- 目标：用户打开页面的第一秒，就被"这竟然是一个让你亲手训练 LLM 的教学工具"的质感震撼。

### 1.6 UI 风格：数学手稿 × 科技反差（已定基调）
- **主基调**：数学手稿美学——暖羊皮纸底、墨黑、朱砂印章红、中文衬线 + 楷体手写批注、纸张纹理、墨迹渐变、尺规线、页码、装订线、图章。
- **核心张力**：与科技/前沿/IT 的反差感——"手稿上长出数字生命"：
  - 纸是旧的，算的是最前沿的；笔是手写的，结果是 AI 的。
  - 反差即祛魅：前沿科技的内核，不过是一张纸能写完的算术。
- **反差元素**：青磷光/电光蓝高亮、发光热力图、闪烁数据点、实时曲线、tabular 等宽数字读数。
- **反差爆点**：
  1. 手写权重表 ↔ 旁边发光的实时 Attention 热力图并排；
  2. 图章盖"训练师认证 · 第 N 阶段完成"（传统图章 × 数字状态）；
  3. 生成时文本像墨水自动书写，热力图逐格亮起；
  4. 纸张边缘藏着现代交互（tooltip/进度条/参数滑杆）——古典外表，现代内核。

### 1.4 命名
- 中文品牌：**AI 学习本**
- 英文/代码名：**AI Notebook**
- 副标题："给你权重，亲手算出它的下一句话"
- 代码目录 `F:\ssslm` 保留；品牌体现在 package.json / README / 页面标题。

## 4. 核心体验：三阶段训练师旅程

> 用户不是观众，而是**做自己的训练师**——不代入任何角色、不做环境扮演，用户只是在使用这个真实工具亲手完成三阶段训练。三阶段**权重连续继承**（阶段一的产出自动成为阶段二起点，以此类推），每阶段成果**可保存/加载/重置**。

### 4.1 模型与参数
- 架构：**结构完整的微型 Transformer**（embedding + 多头注意力 + FFN + LayerNorm，一个不少）。
- 参数规模：**滑杆可调**，最小 ~300 参数（vocab=32、context=8、d=4 级别）。**不设硬上限——自由度拉满**（用户想怎么调就怎么调，卡顿/训崩都是教学的一部分）。
- 教学点：滑杆推大 → 生成质变 + 变慢，用户亲历"scale 的魔力"。

### 4.2 阶段一：预训练（Pretraining）
- **任务**：预测下一个字（自监督 next-token prediction）。用户提供/选择语料、调参数、亲手训练。
- **数据**：内置现代文 / 用户粘贴文本。
- **控制**：参数滑杆、学习率、epoch、batch、训练步数；**自动 + 可单步/暂停**。
- **真实反馈**：loss 实时曲线、权重热力图从"雪花"长成"纹理"、随时暂停生成看效果。
- **硬核点**：调大学习率会训崩（loss 发散）、调太低学不动——用户真的会踩坑。
- **产出**：会"续写"的通才模型。

### 4.3 阶段二：监督微调（SFT）
- **任务**：让模型学会"回答问题"而非"接着写"。用户自己写问答对、亲手微调。
- **数据**：用户提供/内置的"提问→回答"对，带 `<user>/<assistant>` 格式标记。
- **训练**：**在阶段一权重上继续真实训练**（换数据格式）。
- **教学点**：微调前后对比——同一模型从"续写"变"回答"，数据格式改变模型行为。
- **硬核点**：问答对写少了没效果、写多了过拟合。
- **产出**：会回答的助手模型。

### 4.4 阶段三：偏好对齐（DPO）
- **任务**：让模型偏向"更好的回答"。用户亲手标注偏好——这正是 OpenAI 数据标注员做的真实工作。
- **数据**：**用户亲手标注**——模型对同一提问给出 2 个回答，用户选"哪个更好"。
- **算法**：**DPO（Direct Preference Optimization）**——用偏好对做对比学习，无需单独奖励模型，极小模型可真实运行。附 **PPO 科普对照**（传统 RLHF 怎么做、为什么 DPO 更简单——InstructGPT 论文为出处）。
- **教学点**：模型从"两个回答五五开"逐渐偏向用户喜欢的风格。
- **硬核点**：这是真实前沿技术（DPO 2023 论文），且结果取决于用户的标注。
- **产出**：更讨喜、符合用户偏好的模型。

### 4.5 权重状态管理
- 三阶段共用同一权重，连续继承。
- **保存/加载**：localStorage 存权重快照（多快照可对比）。
- 训练后**一键导出权重**为 .txt/.csv（"训练师资产"）。

### 4.6 三阶段视觉仪式（无角色扮演，纯视觉语言）
> 不给人设、不代入环境——以下是**纯视觉的仪式感**，让三阶段像一部手稿的三章，色调递进本身就是"时间感"。

| | 阶段一 预训练 | 阶段二 SFT | 阶段三 DPO |
|---|---|---|---|
| 章节意象 | 誊写星表（语料如古籍誊本，权重"雪花→纹理"如墨迹晕开成星图） | 朱批课业（问答对如被红笔批注的作业） | 判词落印（偏好标注如呈堂证供） |
| 主色调 | 墨黑（纸感最强） | 墨黑 + **朱砂登场** | 朱砂 + **印章** |
| 仪式动效 | 语料誊写感；loss 曲线如手绘观测轨迹 | "续写→回答"用**红笔划线改写**动效；`<user>/<assistant>` 如批注符号 | 用户点选偏好如**画押**，图章盖下"已裁决"；盲测揭晓如盖"最终裁决"章 |

- 视觉叙事弧：**观测 → 批改 → 裁决**（这是界面语言的递进，不是用户身份）。

## 5. 设计铁律（贯穿全项目）

### 5.1 自由度铁律
- 所有状态可**保存/加载/重置**（localStorage）。
- 超参数随便调、随便试错——训崩也没关系，那是教学。
- 每个板块都开放"玩"：如 DPO 后微调前后模型并排随时对比生成。
- **无预设结果、无剧本**——模型长什么样取决于用户自己的操作。

### 5.2 可视化可读性铁律
> **每一个可视化元素，用户都必须能回答："我在看什么、它从哪来、它意味着什么。"**

四条检查（任何可视化过不了任一条就得重做）：
1. **物理隐喻一致**：每个可视化必须对应一个具体数学对象；禁止凭空出现的视觉元素；每个颜色/格子/动画都能翻译回一个数字。
2. **语义标签齐全**：面板标题用中文自然语言（"这是词向量表：把每个字变成 4 个数"）；颜色有图例、范围、单位。
3. **因果可追溯**：可视化能追溯计算链（attention 权重 → 决定下一 token 向量加权 → 影响概率）；点击格子高亮其计算链。
4. **交互即教学**：悬停显示数值+一句中文解释；点击弹出更深说明。

双保险机制：
- 每个面板角落 **"❓这是什么"按钮** → 2~3 句中文解释。
- **"数字视图"切换** → 任何可视化都能切回纯数字表格。

### 5.3 彩蛋原则（彩蛋是设计的一部分）
> 彩蛋不是附加物，而是与"自由度铁律"协同的核心设计——**发现彩蛋 = 奖励探索的用户**。多埋，让探索本身成为乐趣。

四条原则：
1. **不干扰主流程**：发现前绝不露痕迹，不打断实验台操作。
2. **契合灵魂**：每个彩蛋都服务于祛魅/手算/数学手稿×科技反差，不低俗、不凑数。
3. **可复现也可是意外**：有的有明确触发条件（可复现），有的随机低概率闪现（意外惊喜）。
4. **与自由度协同**：彩蛋是"乱玩"的额外奖励，鼓励用户自由探索。

**彩蛋库（初始清单，实现时持续添加）**：
| # | 彩蛋 | 触发 | 灵魂契合 |
|---|---|---|---|
| 1 | "没有魔法"——页脚/关于处隐藏一行小字："没有魔法，只有乘法。" | 悬停某特定元素 | 祛魅宣言 |
| 2 | "纸笔译者"——显微镜模式全部算对 3 次后，页边浮现手写批注："你已经成为这台机器的纸笔译者。" | 手算全对 ×3 | 手算主题 |
| 3 | "欧拉的手稿"——loss 首降阈值时，权重热力图短暂闪现 e^{iπ}+1=0 | 训练里程碑 | 数学史 × 手稿 |
| 4 | "致敬 Karpathy"——连续点击生成 5 次，页边浮现 "Let's build GPT!" | 操作节奏 | 参考来源致敬 |
| 5 | "月"——显微镜模式算出"月"字时，背景短暂浮现"床前明月光" | 手算特定结果 | 中文语料 × 手算 |
| 6 | "学习者印"——完成全部三阶段后，图章盖下隐藏的"学习者"印章（区别于普通印章） | 三阶段完成 | 训练师旅程 |
| 7 | "深夜引言"——午夜(00:00-04:00)打开页面，引言区换夜间文案 | 时间条件 | 氛围 |
| 8 | "新星座"——attention 热力图在特定文本上形成星座图案时，浮现"你发现了一座新星座" | 低概率随机 | 星图 × 数字地层 |
| 9 | "无穷小 μ"——参数滑杆拉到最小档，模型名旁出现 μ 标记 | 滑杆极值 | 微小模型 |
| 10 | "这就是全部智慧"——权重 .csv 导出文件末尾附一行 ASCII 小图/注释 | 导出权重 | 打印权重 × 祛魅 |

## 6. 推理区（四件套验收台）

### 6.1 定位
推理区是"训练成果的验收台 + Transformer 教学高潮 + 性能对比场"。在长页中**贯穿三阶段**：每阶段训练区下方有生成面板，可随时暂停训练试手感。

- **训练暂停后"生成"按钮从灰变亮**（"放下工具，验收作品"的仪式感）。
- 生成是"暂停后的独立操作"，与训练互斥。
- 统一面板 + **阶段感知**：预训练只解锁"续写"；进 SFT 解锁"问答"；进 DPO 解锁"偏好对比/盲测"。
- 上方常驻"当前模型状态条"（阶段标识、参数、保存/加载）。

### 6.2 组件一：显微镜模式（手算 / 演示）
> "给你权重集和纸笔，你说可以把 LLM 的下一句话算出来。"

**入口**：任意模型状态下，推理面板"🔬 显微镜"按钮。

**双档（用户自由选择，可切换）**：
- **档位一 · 看演示**：系统用**当前模型真实权重**逐步播放完整前向传播（embedding → attention → FFN → softmax），每步配讲解卡片（"这是点积：0.12×0.2 + ... = 0.09"）。结束语："没有魔法，只有乘法。"
- **档位二 · 自己算**：提供完整权重表 + 前向传播骨架图 + 每步输入框 + 实时校验。用户手握计算器查表算出中间值，全部算对触发高潮："你算出了模型预测的下一个字：月。"

**已定决策**：
- 模型来源：**用当前训练的模型**（context 截取前 3 字，d 固定教学档）。
- 计算器：**内置计算器 + 允许外置纸笔/手机**。
- 校验：**宽容**——可跳过步骤，但鼓励走完。
- 打印权重：**实时权重面板**（常驻可折叠查表工具）+ **一键导出 txt/csv**。

### 6.3 组件二：Attention 直播
- 生成每个 token 时，热力图实时更新：**行=当前生成的字，列=它看的前文**（轴标签直接写中文字，不显示 token ID）。
- 当前 token 在文本流和热力图上**同步高亮**。
- 每格=注意力权重，图例说明"总和=100%"，悬停显示精确值。
- **默认累积 + 当前行高亮**（可切换为只看最新行）。
- **文本流与热力图同节奏步进/暂停**（锁定同步）。
- 点击格子 → "这就是你手算时算过的那个加权平均系数"，可跳显微镜模式对应步骤。
- 提供慢速/逐步模式（每生成一个 token 暂停，看清这一行）。
- 单头/多头：极小模型单头最清晰；参数变大后默认显示"平均"，可展开看每个头。

### 6.4 组件三：流式生成 + 生成控制
- 逐 token 追加显示，当前 token 高亮（颜色随概率浓度变化——"模型有多自信"）。
- **temperature 滑杆**（0.1~1.5）+ 概率分布条实时变形（拖滑杆看分布变钝/变尖）。
- **生成中可实时调参**：生成进行中拖 temperature，下一个 token 立即按新参数采样。
- prompt 文本框 + 示例按钮（预置现代文开头）。
- 随机种子（复现同一次生成）。
- 最大长度 + 停止符。
- top-k / top-p：进阶折叠区（默认收起）。

### 6.5 组件四：性能仪表 + 盲测
- 实时显示 **ms/token 和 tokens/s**。
- 与参数滑杆联动教学："参数越大生成越慢——为什么大模型需要 GPU"。
- 长文本生成用 rAF/异步避免 UI 卡死。
- **盲测（DPO 验收）**：同一 prompt，微调前后两个模型各生成一次**并排展示**，用户点选"哪个更像训练后的"，然后揭晓。配合"自由度铁律"，DPO 后两个模型可自由反复对比。

## 7. 数据与语料

- **内置语料（3 篇，每篇 ~1000 字）**：朱自清《荷塘月色》节选（现代散文）、刘慈欣《三体》节选（科幻）、现代诗（顾城/海子等）。
- **更开放的语料策略**：内置仅为示例，**用户粘贴自定义优先**——任意文本可覆盖/追加。
- **分词**：中文按字切分（天然按字，无需复杂分词器）。
- **不设大小限制**——用户想粘多少粘多少（自由度铁律，不做性能预设）。

## 8. 双层讲解（雅俗共赏）

- **形态：纸张翻面**——正面直觉（新手层），背面严谨（进阶层）。
- **正面（新手层，默认）**：页边批注，楷体手写小字（"这一步是点积——把两个数字对应相乘再加起来"），悬停展开，保持纸张干净。
- **背面（进阶层）**：纸张翻面，露出完整公式 + 权重数字 + 推导（引用 d2l/论文原文）。
- **交互**：每章右上角"翻面"按钮；**默认停在正面**（新手友好），翻面看严谨细节。
- 来源参考：Karpathy 博客、CS231n、D2L、论文原文。
