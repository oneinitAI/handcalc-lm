# 手算LM · UI 设计逻辑（Design System）

> 数学手稿 × 科技反差 —— 纸是旧的，算的是最前沿的；笔是手写的，结果是 AI 的。

## 0. 设计原则（为什么长这样）

1. **手稿质感**：界面是一本"数学手稿"——纸、墨、朱砂、印章、装订线、尺规网格。所有视觉元素都有"纸笔"的物理隐喻。
2. **科技反差**：手稿上"长出数字生命"——青磷光读数、发光热力图、tabular 数字。旧纸 × 新算法 = 祛魅宣言。
3. **可读性至上**（铁律）：每个可视化必须能回答"我在看什么/它从哪来/意味着什么"；每个控件必须说明"它是干什么的"。炫技是敌人。
4. **教学服务**：视觉不是装饰，是理解模型的手段。艺术性服务于"看懂"。

## 1. 设计 Token

### 1.1 色彩（语义化，禁止在组件里写裸 hex）

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#f1e9d7` | 页面羊皮纸底 |
| `--paper-2` | `#faf5e8` | 卡片纸面 |
| `--ink` | `#2b2620` | 正文墨色（对比 ≥13:1） |
| `--ink-soft` | `#5f5749` | 次级文本（对比 ≥4.5:1） |
| `--ink-faint` | `#9a9184` | 弱提示（仅非关键） |
| `--accent` 朱砂 | `#b3442c` | 主操作/标题/印章（对比 ≥4.5:1） |
| `--glow` 青磷 | `#1f7a6d` | 实时数据/科技反差（对比 ≥4.5:1） |
| `--line` | `#d8cdb8` | 分隔线/边框 |

错误/成功色仅配合文字使用，不单靠颜色传达信息。

### 1.2 字体

- 正文：`--serif`（Songti SC / STSong / SimSun）——手稿正文
- 批注/印章：`--kai`（Kaiti SC / KaiTi）——手写批注
- 数字/代码：`--mono`（Cascadia Mono / Consolas）——tabular 数字、loss、权重、计算器
- 字号阶梯：12 / 13 / 14 / 15 / 16 / 18 / 20 / 24 / 32 / 44 px
- 正文行高 1.85（手稿疏朗感）

### 1.3 间距（4px 网格）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 px`。卡片内边距 18~22px，卡片间距 26px，触控元素间距 ≥8px。

### 1.4 圆角 / 阴影 / 边框

- 圆角：小元素 2px，卡片 3px，胶囊 20px
- 阴影：卡片纸页堆叠（1 层 + 6~18px 环境光）；悬停提升
- 装订线（卡片左缘 3px 朱砂渐变）是"手稿章"识别特征

### 1.5 动效（统一节奏）

- 微交互：150~300ms，`ease-out` 进入 / `ease-in` 退出
- 印章/彩蛋：spring 弹跳 `cubic-bezier(0.34,1.56,0.64,1)`
- 只动 `transform`/`opacity`（避免 CLS）
- **必须支持 `prefers-reduced-motion`**

## 2. 组件规范

| 组件 | 规范 |
|---|---|
| **按钮 .btn** | primary=墨底纸字；ghost=纸底+线框；hover 墨迹晕染；active scale 0.94；disabled opacity 0.4；触控高 ≥40px |
| **chip .chip** | 胶囊、楷体、悬停朱砂描边+光晕；on=朱砂填充；active scale 0.94 |
| **卡片 .card** | paper-2 底、1px 线、装订线、纸堆叠阴影；h2 朱砂+底线（章节号） |
| **输入框** | paper 底、1px 线、聚焦朱砂描边+光晕；可见 label，不放 placeholder-only |
| **热力图** | 暖色映射（纸→朱砂）；悬停显示精确数值；颜色+数字双通道 |
| **进度条** | 墨槽+朱砂渐变填充；tabular 百分比（青磷） |
| **toast** | 墨底纸字、右上角、3s 消失、`aria-live` |
| **details** | summary 青磷字；渐进披露（进阶参数默认收起） |

## 3. 交互规范

- **每个控件必须有 title 或可见提示**（"它是干什么的"）——无解释的控件不允许存在
- hover 不能是唯一交互（触屏要有 active 反馈）
- 状态切换平滑（150-300ms），不瞬跳
- 破坏性操作（重建）确认/提示
- 训练/生成中按钮禁用（防重复）

## 4. 可访问性（CRITICAL）

- 正文对比 ≥4.5:1（ink on paper ≈13:1；ink-soft ≈4.8:1）
- `:focus-visible` 朱砂焦点环，键盘完整操作
- 颜色不作为唯一信息通道
- 触控目标 ≥44×44px
- toast 用 `aria-live`；实时数据不抢焦点
- 支持 `prefers-reduced-motion`

## 5. 响应式

- 容器 max-width 680px（60~75 字符行宽）
- 断点 560px：双列→单列（viz-row/pair/glossary）、标题缩小、隐藏题签印章
- 表格（ms-table/ms-wte）溢出→横向滚动
- canvas resize 重绘（不拉伸错位）

## 6. 视觉层级

1. 旅程地图（intro）→ 用户知道去哪
2. 章节卡（壹~玖）→ 手稿"章"，朱砂 h2
3. 实时数据（loss/进度/概率）→ 青磷 tabular + 呼吸动效
4. 讲解（howTo/notes/术语表）→ 楷体批注，展开式，不抢主流程
